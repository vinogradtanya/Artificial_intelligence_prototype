# AI Content Studio — учебный прототип

Урезанный учебный прототип веб-сервиса генерации контента (текст / изображение / аудио).
Демонстрирует ключевые механики продукта, **не претендуя на промышленную эксплуатацию**.

> Реальный ИИ-сервис подменён **Mock-генератором**; реальная оплата — кнопкой
> «Пополнить»; модерация — проверкой по списку запрещённых слов; экспорт — только CSV/JSON.

## Соответствие пунктам сокращённого ТЗ

| Требование ТЗ | Реализация | Где в коде |
|---|---|---|
| Регистрация и авторизация (хеширование) | Логин/email/пароль, `werkzeug.security` | `app/auth.py`, `app/models.py` |
| Личный кабинет: профиль и тариф | Профиль, смена email/пароля, тарифы free/pro/business | `app/main.py`, `templates/cabinet.html` |
| Создание «проекта» (тип, промпт, параметры) | Форма с выбором типа и параметров | `app/projects.py`, `templates/project_new.html` |
| Имитация генерации | Изображение и аудио — **реальные** (Pollinations.AI / TTS) с откатом на mock; текст — mock по ключевым словам; опц. HF API | `app/generator.py` |
| Сохранение в «библиотеку» (БД) | SQLite, таблица `generations` | `app/models.py`, `schema.sql` |
| История генераций с фильтрами по дате/типу | Страница истории + фильтры | `app/reports.py`, `templates/history.html` |
| Имитация баланса токенов | Списание при генерации, пополнение (mock) | `app/models.py`, `app/main.py` |
| Базовая модерация (список слов, `includes`) | Массив `FORBIDDEN_WORDS` + проверка подстроки | `app/moderation.py` |
| Две роли: пользователь / администратор | Блокировка пользователей, статистика | `app/admin.py`, `app/security.py` |
| Отчёты: генерации и транзакции с фильтрами | Разделы «История» и «Транзакции» | `app/reports.py` |
| Один формат экспорта | CSV **и** JSON | `app/reports.py` |
| AI-ассистент: справочник + подсказки промптов | Офлайн-база знаний + LLM-подсказки с откатом | `app/assistant.py` |

## Стек

- **Python 3.11+** (проверено на 3.14)
- **Flask 3** — веб-фреймворк
- **SQLite** (стандартная библиотека `sqlite3`) — БД; драйверы PostgreSQL/MySQL доступны и заявлены как перспектива
- **Pillow** — обработка/генерация изображений
- **Pollinations.AI** — реальная генерация изображений по промпту (бесплатно, без ключа)
- **Windows SAPI5 (`System.Speech`)** — реальная озвучка текста (офлайн)
- **`wave` / `struct` / `math`** — генерация аудио-заглушек
- **pytest** — модульные тесты

## Быстрый старт

```powershell
python -m pip install -r requirements.txt

# (необязательно) наполнить БД демо-данными и создать администратора
python seed.py

# запуск dev-сервера
python run.py            # http://127.0.0.1:5000
```

Учётные записи по умолчанию (после `python seed.py`):

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | администратор |
| `ivan` / `petr` / `anna` / `olga` / `sergey` | `user123` | пользователь |

Можно также зарегистрировать нового пользователя — он получит стартовый баланс 100 токенов.

## Тесты

```powershell
python -m pytest          # 82 теста
```

Покрыты: аутентификация, модерация, mock-генерация (текст/изображение/аудио),
реальные движки (Pollinations/TTS с откатом), сквозной сценарий генерации со списанием
токенов, баланс и тарифы, экспорт CSV/JSON, права администратора и блокировка,
AI-ассистент (справочник и LLM-подсказки).

## Структура проекта

```
app/
  __init__.py      # фабрика приложения
  config.py        # конфигурация (токены, тарифы, лимиты)
  db.py            # подключение к SQLite и инициализация схемы
  models.py        # доступ к данным и бизнес-логика
  security.py      # загрузка пользователя, декораторы прав
  moderation.py    # модерация по списку запрещённых слов
  generator.py     # Mock-генератор + опциональный Hugging Face API
  auth.py          # регистрация/вход/выход
  main.py          # дашборд, кабинет, тариф, пополнение
  projects.py      # создание генерации, библиотека, выдача медиа
  reports.py       # история, транзакции, экспорт CSV/JSON
  admin.py         # панель администратора
  assistant.py     # AI-ассистент: справочник + подсказки промптов (LLM)
  templates/       # Jinja2-шаблоны
  static/style.css # оформление
docs/              # документы по ГОСТ (см. docs/README.md)
tests/             # pytest
schema.sql         # схема БД
seed.py            # наполнение демо-данными
run.py             # точка входа
```

## Заглушки

| В полном ТЗ | В прототипе |
|---|---|
| Реальный AI API (текст) | Mock-генератор (опционально бесплатный HF API) |
| Реальный AI API (изображения) | **Реально**: Pollinations.AI (бесплатно); откат на mock |
| Реальный синтез речи | **Реально**: голос Windows (SAPI5, офлайн); откат на мелодию |
| AI-ассистент (понимание вопросов) | **Реально**: офлайн-справочник + LLM по ключу; без ключа — справочник |
| Реальная оплата | Кнопка «Пополнить» → запись в БД |
| Модерация моделью | Проверка по списку запрещённых слов |
| PDF/Excel экспорт | CSV / JSON |
| 1000 пользователей | 10–20 пользователей в тестах |
| Резервное копирование | Не реализуется, только декларируется |
| Тёмная тема | Реализована по умолчанию (интерфейс тёмный) |

> **ВАЖНО:** каждый реальный движок выбирается настройками (`USE_REAL_IMAGE`,
> `USE_REAL_AUDIO`) и при любой ошибке (нет сети, лимит сервиса, сбой TTS)
> автоматически откатывается к детерминированному mock — система не падает.
