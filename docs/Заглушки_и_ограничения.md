## 2. Реальные движки генерации

| Тип | Движок | Условие включения | Офлайн? |
|---|---|---|---|
| Изображение | Pollinations.AI (`image.pollinations.ai`) | `USE_REAL_IMAGE=1` (по умолчанию) | нет |
| Аудио (речь) | Windows SAPI5 `System.Speech` | `USE_REAL_AUDIO=1` (по умолчанию) | да |
| Текст | Hugging Face Inference API | `USE_REAL_API=1` + `HF_API_TOKEN` | нет |
| Ассистент (ответы) | LLM по OpenAI-совместимому API | `ASSISTANT_API_KEY` | нет |

- **Изображения.** Промпт отправляется в бесплатный сервис
  [Pollinations.AI](https://pollinations.ai); полученный файл (JPEG) приводится
  библиотекой Pillow к PNG. Сервис бесплатный и не требует ключа, но отвечает
  нестабильно (иногда HTTP 402/пустой ответ), поэтому предусмотрены повторные
  попытки (`IMAGE_RETRIES`) и отбраковка «пустых» ответов.
- **Аудио.** Текст промпта озвучивается системным голосом Windows (движок SAPI5).
  Реализация — вызов `System.Speech` через PowerShell; пользовательский текст
  передаётся через переменные окружения (не в командной строке), что исключает
  инъекцию команд. При наличии голоса `ru-RU` он выбирается автоматически.
  Функция доступна только в Windows (`os.name == "nt"`).
- **Текст.** Опционально можно подключить бесплатный Hugging Face Inference API
  (`generate_text_real`).

## 3. Mock-заглушки и автоматический откат

Каждый движок при **любой** ошибке (нет сети, таймаут, лимит сервиса, недоступность
TTS) откатывается к детерминированному mock-генератору — система никогда не падает:

- **Текст** — шаблон по ключевым словам промпта (стих, сказка, поздравление, слоган,
  код) либо обобщённый ответ.
- **Изображение** — PNG: градиент (цвета из хеша промпта) и текст промпта (Pillow).
- **Аудио** — WAV: короткая мелодия из нот, выбранных из хеша промпта
  (модули `wave`/`struct`/`math`).
- **Ассистент** — офлайн-ответ по базе знаний (`KNOWLEDGE_BASE`, 19 тем) и шаблонные
  советы по промптам (`PROMPT_HINTS`), если LLM недоступен.

Детерминированность mock-режима означает: одинаковый промпт даёт одинаковый результат —
это удобно для автотестов и демонстраций. Движок, которым получен результат, виден в
сообщении после генерации: `pollinations` / `sapi5-tts` / `hf` / `mock`.

## 4. Ограничения

1. **Не промышленная система.** Нет отказоустойчивости, балансировки, очередей.
2. **Один узел, SQLite.** Не тестировался конкурентный доступ многих пользователей.
3. **Безопасность.** `SECRET_KEY` и пароли по умолчанию — демонстрационные; отсутствуют
   CSRF-защита форм, ограничение частоты запросов, подтверждение email.
4. **Медиафайлы.** Хранятся в файловой системе (`storage/media/`), без CDN и очистки.
5. **Восстановление пароля** не реализовано.
6. **Масштаб данных** — десятки пользователей и сотни записей.

## 5. Границы объёма (обязательное / перспективное)

- **Обязательное** (реализовано и покрыто тестами): Ф-01…Ф-16 из `docs/ТЗ.md`.
- **Перспективное** (вне объёма): П-01…П-08 из `docs/ТЗ.md`, раздел 10.2.

Такое разграничение — законная инженерная практика (MVP + развитие на следующих
итерациях), согласованная с подходами ГОСТ 34.602-2020 и ГОСТ Р 57193-2025.
