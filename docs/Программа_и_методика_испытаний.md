# Программа и методика испытаний

_(оформлено по ГОСТ Р 59792-2021, применительно к учебному прототипу)_

## 1. Объект испытаний

Система «AI Content Studio» — учебный прототип (комплект программ `app/`, схема БД
`schema.sql`, тесты `tests/`).

## 2. Цель испытаний

Установить соответствие прототипа обязательным требованиям ТЗ (функции Ф-01…Ф-16),
проверить работоспособность и корректность ключевых сценариев, оценить полноту
документации.

## 3. Требования к программной документации

Предъявляются: `docs/ТЗ.md`, `docs/Руководство_пользователя.md`, `README.md`,
настоящая программа и методика.

## 4. Состав технических средств

ПК с Python 3.11+; зависимости из `requirements.txt` (Flask, Pillow, pytest).
Внешние платные сервисы не требуются (Mock-генератор).

## 5. Виды испытаний и порядок проведения

Испытания проводятся в три этапа в соответствии с учебным процессом:

| Этап | Соответствие ГОСТ | Форма проведения |
|---|---|---|
| **Модульные (автоматические) испытания** | предварительные | `python -m pytest` |
| **Демонстрация** | опытная эксплуатация | запуск сервера, показ сценариев преподавателю |
| **Защита проекта** | приёмочные | защита перед комиссией |

Команды запуска:

```powershell
python -m pytest          # автотесты: ожидается "50 passed"
python seed.py            # демо-данные
python run.py             # ручная проверка: http://127.0.0.1:5000
```

## 7. Оценка результатов

Оценка «испытания пройдены», если: (а) все автотесты успешны; (б) все ручные проверки
M-01…M-08 дали ожидаемый результат; (в) документация комплектна.

При несоответствии оформляется протокол замечаний для стадии «Сопровождение».
