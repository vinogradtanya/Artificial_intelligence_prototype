# Руководство пользователя

## 1. Назначение

Руководство описывает работу с учебным прототипом «AI Content Studio»: генерацию
текста, изображений и аудио, работу с библиотекой, балансом токенов и отчётами.

## 2. Запуск системы

```powershell
python -m pip install -r requirements.txt
python seed.py        # создать БД, администратора и демо-данные (необязательно)
python run.py         # http://127.0.0.1:5000
```

Учётные записи:

- администратор: `admin` / `admin123`
- пользователь (демо): `ivan` / `user123` (а также `petr`, `anna`, `olga`, `sergey`)

## 3. Регистрация и вход

1. Откройте «Регистрация», укажите логин (≥3 символов), email, пароль (≥6 символов).
2. Новому пользователю начисляется стартовый баланс — 100 токенов.
3. Войдите через страницу «Вход» (можно указать логин **или** email).

## 4. Личный кабинет

Раздел «Кабинет» содержит:

- **Профиль** — смена email и пароля;
- **Пополнение баланса** — имитация оплаты: введите сумму и нажмите «Пополнить».
  Реальный платёж не производится, баланс увеличивается, создаётся транзакция;
- **Тариф** — переключение между `free` / `pro` / `business`;
- **Последние транзакции**.

### Тарифы и стоимость

| Тариф | Коэффициент стоимости | Бонус пополнения |
|---|---|---|
| free | ×1.0 | 0% |
| pro | ×0.8 | 5% |
| business | ×0.5 | 10% |

Базовая стоимость генерации: текст — 10, изображение — 50, аудио — 30 токенов.

## 5. Создание генерации

1. Откройте «Генерация».
2. Выберите **тип контента**: текст, изображение или аудио.
3. Введите **промпт** и при необходимости настройте параметры
   (длина текста; размер изображения; длительность мелодии-заглушки).
4. Нажмите «Сгенерировать». Система:
   - проверяет промпт по списку запрещённых слов (модерация);
   - проверяет достаточность баланса;
   - формирует результат и списывает токены.

**Как формируется результат:**

- **Изображение** — реальная генерация по промпту бесплатной AI-моделью
  (Pollinations.AI). **Промпт можно писать по-русски** — сервис понимает
  русскоязычные описания (проверено), хотя для сложных сцен англоязычные
  формулировки иногда дают более точный результат.
- **Аудио** — реальная озвучка текста промпта системным голосом Windows
  (движок SAPI5). Русская речь озвучивается голосом `ru-RU`, если он установлен.
- **Текст** — встроенный mock-генератор (шаблон по ключевым словам промпта).

Если внешний сервис недоступен (нет интернета) или синтез речи не сработал,
автоматически создаётся **заглушка** — генерация всё равно завершится успешно.
Движок указан в сообщении после генерации: `pollinations`, `sapi5-tts` или `mock`.

При недостатке токенов генерация не выполняется — пополните баланс.
При срабатывании модерации токены **не** списываются.

## 6. Библиотека

Раздел «Библиотека» содержит результаты успешных генераций с фильтрами по типу и датам.
Откройте запись, чтобы увидеть результат:

- текст — отображается целиком;
- изображение — PNG с возможностью скачивания;
- аудио — встроенный плеер и скачивание WAV.

Любую запись можно удалить.

## 7. История и отчёты

- **История** — все генерации (включая отклонённые) с фильтрами по типу и датам.
- **Транзакции** — движения по балансу с фильтрами по датам.
- **Экспорт** — кнопки «Экспорт CSV» и «Экспорт JSON» на страницах истории и транзакций.
  Файлы пригодны для открытия в Excel/табличных редакторах (CSV с BOM) и в программах.

## 8. AI-ассистент

Раздел «Ассистент» содержит два инструмента:

1. **Спросить о системе.** Задайте вопрос о работе сервиса — например, «как пополнить
   баланс?», «почему промпт отклонён?», «как озвучивается аудио?». Ответ формируется по
   встроенной базе знаний; указывается источник и похожие темы. Есть кнопки популярных
   вопросов.
2. **Подсказка к промпту.** Выберите тип контента, введите ваш промпт — ассистент
   предложит улучшенную формулировку и советы по его составлению.
   **Весь текст — на русском языке**, включая улучшенный промпт.

**Как это работает.** Если задан бесплатный ключ LLM-API (переменная
`ASSISTANT_API_KEY`), ответы и подсказки формируются языковой моделью (бейдж «LLM включён»).
Без ключа (или при сбое сети) ассистент работает в офлайн-режиме по базе знаний и
шаблонным советам (бейдж «офлайн-справочник»), поэтому он всегда доступен.

Пример подключения бесплатного ключа Groq:

```powershell
$env:ASSISTANT_API_KEY = "ваш_бесплатный_ключ"
python run.py
```

## 9. Возможности администратора

Администратор дополнительно может:

- просматривать **статистику** (число пользователей, генераций, токенов, топ активных);
- **блокировать/разблокировать** пользователей (заблокированный не может войти);
- смотреть **журнал действий** (аудит);
- переключать область отчётов на **«Все пользователи»**.

## 10. Частые вопросы

- **Забыли пароль?** В прототипе восстановление не реализовано — создайте нового
  пользователя или измените пароль через администратора (в БД).
- **Ничего не генерируется.** Проверьте баланс (нужно ≥ стоимости) и промпт (модерация).
- **Нужен «настоящий» ИИ.** Изображения уже генерируются реально (Pollinations.AI),
  аудио — реальным голосом. Для реального текста установите `USE_REAL_API=1` и
  `HF_API_TOKEN`. Отключить реальные движки можно настройками `USE_REAL_IMAGE=0`
  и `USE_REAL_AUDIO=0`.
