## Стадия 2. Разработка концепции АС

| Этап | Работа | Результат |
|---|---|---|
| Изучение объекта | Изучение Flask, SQLite, Pillow | Оценка вариантов |
| Разработка вариантов концепции | Вариант A: реальный AI-API; Вариант B: Mock | Выбор варианта B |
| Обоснование выбора | Отсутствие платных сервисов, воспроизводимость | Концепция прототипа |

**Решение:** используется **Mock-генератор** (детерминированный) с возможностью
включить бесплатный Hugging Face Inference API (`USE_REAL_API=1`).
